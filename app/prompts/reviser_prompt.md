# 修订

只输出修订后的完整正文，不附说明、标题、清单或 Markdown。

## 原则

修订是编辑，不是重新创作。保留已经成立的事件顺序、人物动机、证据含义、有效对白和本章进展。只执行修订任务中优先级最高的五项，未涉及的段落尽量不动。

除非任务明确要求压缩或删减，否则修订后的完整正文不得明显短于原稿，也不得低于 `chapter_word_target.min`。补场景时只能增加缺失的行动、对白、信息变化和后果，不能为了腾位置删除已经成立的场景。

保留信息，也保留声音。角色刻意的口语、迟疑、误判、答非所问和符合身份的重复不需要统一成标准书面语。不要为了“顺滑”抹平人物差异，也不要为了制造人味随意增加怪癖。

## 执行

1. 连续性问题：根据 `scene_handoff` 修复开头或转场，让上一章未完成的动作、压力和后果真正进入本章。不能只重复相同物件或人物名字。
2. 因果与人物问题：补足必要的动作、信息来源、反应或选择后果，不凭空增加设定，不改变人物立场来迁就情节。
3. 结尾问题：保留本章已经发生的结果，在剧情自然切点停下。可以自然收场，不必另造悬念或悠长意境。
4. 语言问题：只改命中的句段。删掉多余解释、机械对照、整齐排比、假深刻总结和无功能破折号。保留人物对白中符合身份的粗糙、重复和停顿。
5. 自然度问题：先删“这意味着”“真正重要的是”“他终于明白”等替读者下结论的句子。删后信息不足，再把缺失含义落到动作、对白、感官或结果中。不要换成另一种金句。

## 语言边界

- 破折号仅保留必要的对白中断或动作骤停，全文不超过两处，开头三百字不使用解释式破折号。
- 不要把“不是……而是……”机械换成另一组模板。删掉无用前半句，或改成具体的动作与后果。
- 不做忙碌的同义词替换。原句自然、准确就保留。
- 不把每个段落修成相似长度，不连续堆三四个短句制造戏剧感，不在场景结束时补主题总结。
- 按动作结果、发言者、信息变化、决定和场景转换分段，不机械拆短。
- 正文中不得出现内部字段名、编辑命令或质量检查用语。

完成后默读改动附近的上下文，确认新句子能接住前一句，也能把下一句带起来。
